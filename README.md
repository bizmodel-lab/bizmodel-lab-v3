# 创见 BizLab V3 — 商业模式设计实训系统

面向高校创业课程 / SYB 培训的商业模式设计实训系统 V3。教师创建课程、管理学生、按六阶段批阅并查看教学看板；学生按「机会识别 → 客户洞察 → 商业模式 → 验证迭代 → 财务测算 → 计划书」六阶段完成结构化实训并提交。

## 快速开始（本地）

```bash
# 1. 启动（无需安装任何依赖，仅需 Node.js 18+）
node server.js

# 2. 浏览器访问
http://localhost:8700
```

首次启动自动创建默认管理员账号：
- 账号：`admin`
- 密码：`admin123456`（**登录后请立即在「账号设置」中修改**）

登录后由管理员创建教师账号，学生自助注册并凭课程邀请码加入课程。

## 数据存储

- 单文件 JSON 数据库：`data/db.json`（原子写入，崩溃不损坏）
- 可通过环境变量 `DATA_DIR` 指定数据目录（用于部署到 Render 等平台挂载持久卷）

## 使用流程

1. **管理员**：登录 → 教师账号管理 → 创建教师账号
2. **教师**：登录 → 课程管理 → 创建课程 → 将邀请码发给学生 → 批改学生提交 → 查看进度看板 → 导出成绩 CSV
3. **学生**：注册 → 输入邀请码加入课程 → 按六阶段学习并提交 → 教师批改后查看成绩与评语

```

│   ├── app.html         # 主应用壳
│   ├── css/style.css
│   └── js/
│       ├── api.js       # API 封装与认证
│       ├── student.js   # 学生端视图
│       └── teacher.js   # 教师端 / 管理员端视图
```

## 部署

- 局域网内网穿透（Cloudflared）与 Render 云部署：见 `DEPLOY.md`
- Render 平台配置文件：`render.yaml`

## 开发说明

- 技术栈：纯 Node.js / 原生 JS（零第三方运行时依赖）
- 默认端口 `8700`，可用环境变量 `PORT` 覆盖
- 密码使用 `scrypt` 加盐哈希存储；会话为 Bearer Token（30 天）
- 修改服务端后重启生效；前端文件改动无需重启（静态文件每次读取）
